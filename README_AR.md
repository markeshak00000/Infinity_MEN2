# Infinity MEN2 – نظام إدارة مكتب المحاماة

## الملفات الأساسية
- `index.html`: واجهة البرنامج.
- `app.js`: وظائف وإدارة البرنامج.
- `pwa.js` و`sw.js`: التثبيت والإشعارات والعمل دون اتصال.
- `package.json`: ملف npm الأساسي لتثبيت الحزم وتشغيل وبناء المشروع.
- `capacitor.config.json`: إعدادات تحويله إلى تطبيق Android.
- `assets/`: الشعار وأيقونات التطبيق.
- `resources/`: صور إنشاء أيقونات Android.

## التشغيل على الكمبيوتر
1. ثبّت Node.js 22 أو أحدث.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ: `npm install`
4. نفّذ: `npm start`
5. افتح: `http://127.0.0.1:4173`

## تجهيز Android
نفّذ مرة واحدة: `npm run android:add`
وبعد ذلك لتحديث ملفات التطبيق: `npm run android:sync`
لفتح Android Studio: `npm run android:open`

## الإشعارات الخارجية
التذكيرات المحلية تعمل من داخل التطبيق بعد منح الإذن. الإشعارات الخارجية تحتاج نشر خادم Push وإعداد Firebase. عند الحاجة انسخ `.env.example` إلى `.env` وأدخل بياناتك الحقيقية، ثم ضع ملف Firebase Service Account داخل `.private/firebase-service-account.json` (لا ترسله لأحد ولا ترفعه إلى GitHub). شغّل الخادم بالأمر `npm run push:start` بعد ضبط الإعدادات.

## تنبيه بيانات
البيانات الأساسية محفوظة محليًا على الجهاز. هذه الحزمة لا تحتوي على مزامنة متعددة الأجهزة أو تشفير احترافي لبيانات القضايا؛ لا تضع بيانات قضايا حقيقية قبل إضافة خادم آمن ومزامنة ومراجعة الحماية.
