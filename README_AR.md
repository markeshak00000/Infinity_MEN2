# Infinity MEN2 — نظام إدارة مكتب المحاماة

**الإصدار:** 1.1.0  
**الهوية البصرية:** شعار Infinity MEN2 الذي أرسله صاحب المشروع، دون استخدام شعارات بديلة.

## محتويات المشروع

- `index.html` و`app.js`: واجهة النظام وأقسام إدارة المكتب.
- `assets/brand/infinity-men2-logo.jpg`: نسخة مربعة مناسبة لواجهة التطبيق.
- `assets/brand/infinity-men2-logo-full.jpg`: الصورة الأصلية الكاملة للشعار كما تم إرسالها.
- `assets/icons/`: أيقونات PWA وiOS وMaskable بأحجامها المختلفة.
- `assets/icon-only.png` و`assets/icon-foreground.png` و`assets/icon-background.png` و`splash.png`: مصادر أيقونة وشاشة بداية Android.
- `native/android-res/`: موارد إضافية لأيقونة Android وأيقونة الإشعارات.
- `native-features.js`: ربط الكاميرا والإشعارات الأصلية في Capacitor.
- `pwa.js`: التثبيت، التصوير عبر المتصفح، التذكيرات، والنسخ الاحتياطي والاستعادة.
- `manifest.webmanifest` و`sw.js`: تثبيت PWA والعمل دون اتصال بعد تحميل التطبيق أول مرة.
- `server/`: خادم اختياري للإشعارات الخارجية عبر Web Push وFirebase Cloud Messaging.
- `capacitor.config.json` و`scripts/`: ملفات بناء نسخة Android.

## 1) تشغيل نسخة الويب وتجربتها

المتطلبات: Node.js 22 أو أحدث.

من مجلد المشروع:

```bash
npm install
npm run serve
```

افتح `http://localhost:4173` على الكمبيوتر. لتثبيته على الهاتف ارفع محتويات المشروع أو مجلد الموقع إلى استضافة HTTPS، ثم افتح الموقع من Chrome على Android واختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.

## 2) إنشاء مشروع Android وملف APK

بعد تثبيت Node.js وAndroid Studio وAndroid SDK وJava المناسب لإصدار Android Gradle Plugin:

```bash
npm install
npm run android:add
```

لو مجلد `android` موجود من قبل، استخدم:

```bash
npm run android:sync
npm run android:open
```

بعد فتح المشروع في Android Studio اختر **Build → Build Bundle(s) / APK(s) → Build APK(s)**. مسار APK المعتاد:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

يولّد أمر البناء ملفات Android من مصادر الشعار المرفقة، ويضيف أيقونة الإشعارات الصغيرة. المشروع ZIP يحتوي على المصدر وأدوات البناء؛ لا يحتوي على APK مبني مسبقًا لأن ذلك يحتاج Android SDK على جهاز البناء.

## 3) التصوير وإرفاق صور المستندات

- في إصدار Android الأصلي، زر تصوير المستند يستدعي كاميرا الهاتف من خلال Capacitor Camera.
- في نسخة PWA يفتح المتصفح الكاميرا أو أداة اختيار الصور بحسب دعم الجهاز.
- الصورة تُضغط إلى حد أقصى 1600 بكسل تقريبًا قبل حفظها داخل سجل المستند لتقليل الحجم.
- لا يتم رفع صورة المستند إلى خادم خارجي بواسطة الكود الحالي.

## 4) الإشعارات المحلية وتذكيرات الجلسات

- عند تفعيل الإشعارات من **مركز التطبيق**، يطلب إصدار Android إذن الإشعارات ويختبر ظهور إشعار.
- يحاول النظام جدولة تذكير أصلي لكل جلسة قادمة خلال 90 يومًا: قبل موعد الجلسة بساعة عندما يكون الوقت مسجلًا، أو الساعة 08:00 في يوم الجلسة عندما لا يُدخل وقت.
- عند تعديل الجلسات أو إضافتها أو حذفها، يعيد التطبيق تحديث جدول التذكيرات.
- قد يؤخر Android بعض الإشعارات المجدولة بسبب إعدادات توفير البطارية أو عدم منح إذن المنبهات الدقيقة. Android 13 يتطلب إذن إشعارات، وAndroid 12 وما بعده قد يحتاج إعدادًا إضافيًا للدقة الزمنية؛ لذلك لا أضمن دقة الثانية في كل جهاز.
- في نسخة PWA تُعرض التذكيرات أثناء تشغيل التطبيق. أما وصول Web Push والتطبيق مغلق فيحتاج نشر خادم Push وإعداد مفاتيحه كما في القسم التالي.

## 5) إعداد الإشعارات الخارجية عند إغلاق التطبيق

يوفر المشروع مسارين:

### أ) Web Push لنسخة PWA

1. انشر مجلد `server` على خادم Node.js يدعم HTTPS.
2. انسخ `server/.env.example` إلى `server/.env`، ثم أدخل القيم الحقيقية:
   - `APP_ORIGINS`: عنوان الموقع المنشور، ويمكن إضافة `https://localhost` عند استخدام تطبيق Android الأصلي.
   - `VAPID_SUBJECT`: بريد حقيقي بصيغة `mailto:...` أو رابط اتصال HTTPS.
   - `PUSH_API_KEY`: مفتاح عشوائي طويل يبقى على الخادم فقط.
3. من مجلد `server` نفذ `npm install` ثم `npm start`.
4. ضع عنوان الخادم المنشور باستخدام HTTPS في `config.js`:

```js
window.INFINITY_PUSH_API_URL = "https://عنوان-خادم-الإشعارات";
```

### ب) Firebase Cloud Messaging لإصدار Android

1. أنشئ مشروع Firebase خاصًا بك، وأضف تطبيق Android بمعرّف الحزمة نفسه الموجود في `capacitor.config.json`: `com.infinitymen2.lawoffice`.
2. نزّل ملف `google-services.json` وضعه داخل `android/app/`.
3. أنشئ Service Account من إعدادات Firebase Admin، وضع ملف JSON الناتج في `server/firebase-service-account.json`. **لا تضع هذا الملف داخل مجلد الويب ولا تنشره للعامة أو في GitHub.**
4. تأكد من ضبط `APP_ORIGINS` و`PUSH_API_KEY` و`VAPID_SUBJECT` في `server/.env`، ثم أعد تشغيل الخادم.
5. افتح التطبيق على الهاتف، ثم مركز التطبيق، واضغط **تفعيل إشعارات الجلسات**. سيطلب التطبيق إذن الإشعارات ويسجل رمز هذا الجهاز في الخادم.
6. لإرسال إشعار إلى الأجهزة المسجلة، أرسل طلب POST إلى `/api/push/send` مع ترويسة `Authorization: Bearer PUSH_API_KEY` وبيانات مثل:

```json
{
  "title": "Infinity MEN2",
  "body": "لديك جلسة أو تحديث جديد.",
  "url": "./index.html",
  "tag": "office-update"
}
```

الخادم يرسل عبر Web Push للأجهزة المسجلة في PWA، وعبر FCM لأجهزة Android المسجلة عندما تكون بيانات Firebase موجودة. مفتاح الإرسال لا يوضع في `config.js` أو التطبيق.

## 6) النسخ الاحتياطي والاستعادة

من **مركز التطبيق**:

- **تصدير نسخة احتياطية** ينشئ ملف JSON يشمل سجلات العملاء والقضايا والجلسات والمستندات والمهام والفواتير والإعدادات.
- **استعادة نسخة احتياطية** تدمج السجلات من ملف نسخة احتياطية صالح، ثم تعيد تحميل التطبيق لعرض البيانات.
- لا تشارك ملف النسخة الاحتياطية؛ فقد يحتوي بيانات شخصية وقانونية حساسة.

## 7) التخزين والخصوصية — مهم

- قاعدة البيانات الحالية محلية داخل الجهاز باستخدام IndexedDB. هذا الإصدار لا يزامن البيانات تلقائيًا بين عدة هواتف أو مستخدمين.
- البيانات المحلية ليست مشفّرة على مستوى التطبيق. استخدم قفل الجهاز، ولا تترك الجهاز مفتوحًا، واحتفظ بالنسخ الاحتياطية في مكان آمن.
- تفعيل الإشعارات الخارجية لا يعني أن بيانات القضايا أو المستندات تُرفع إلى خادم Push؛ الخادم يستقبل رموز الإشعارات فقط، ورسالة الإشعار التي يرسلها المسؤول.
- إضافة مزامنة فعلية بين الأجهزة تتطلب خادم بيانات آمنًا، حسابات مستخدمين، صلاحيات، نسخًا احتياطيًا، وتشفيرًا مناسبًا. لم أضع خادمًا عامًا غير محمي لبيانات المكتب.
